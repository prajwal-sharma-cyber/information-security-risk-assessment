# Information Security Risk Assessment

A practical risk-assessment exercise applying asset identification, threat analysis, likelihood, impact, risk scoring and security controls.

## Scenario
A fictional Australian organisation operates a customer portal, internal file server, employee laptops and cloud applications.

## Method
1. Identify assets.
2. Identify threats.
3. Identify vulnerabilities.
4. Estimate likelihood.
5. Estimate impact.
6. Calculate risk.
7. Select treatment.
8. Assess residual risk.

## Formula
`Risk Score = Likelihood × Impact`

Both values use a 1–5 scale.

## Risk Levels
- 1–4: Low
- 5–9: Moderate
- 10–16: High
- 17–25: Critical

## Portfolio Value
Demonstrates that cybersecurity includes governance, risk and decision-making — not only technical tools.
